# 自定义期权轮动交易规则 v1

> 本规范描述用户的个人交易工作流与硬性约束。它是策略规则，不构成投资建议、收益保证或自动下单授权。

## 1. 策略目标与基本流程

本策略不是普通的 Wheel Strategy，而是以“累计期权权利金后的实际持仓成本”为核心约束的期权轮动策略。

基本流程：

1. 在现金状态下卖出 Cash-Secured Put（CSP）。
2. 如果 CSP 未被行权：保留已收取权利金，继续卖 CSP。
3. 如果 CSP 被行权：接收股票，并将此前符合规则的期权权利金计入持仓成本调整。
4. 持有股票后，只允许卖出执行价高于股票实际成本价的 Covered Call（CC）。
5. 如果 CC 未被行权：股票继续持有，可在满足规则时继续卖 CC。
6. 如果 CC 被行权：股票卖出，回到现金状态，可重新卖 CSP。

## 2. 核心定义

### 2.1 名义成本价

名义成本价是通过 CSP 被行权后取得股票时的执行价，或券商账本中显示的股票成本基础。名义成本价不能单独用于判断 Covered Call 的执行价是否合格。

### 2.2 净权利金与累计期权费用

净权利金定义为：

```text
净权利金 = 实际卖出期权收到的权利金 - 手续费
```

本策略中的“所有累计期权费用”是指用户通过卖出期权实际获得并已确认的净权利金总额，包括：

- 卖出 CSP 收到的净权利金；
- 持有股票后卖出 CC 收到的净权利金；
- 同一标的的所有相关 CSP 净权利金；
- 同一标的的所有相关 CC 净权利金；
- 上一轮已经卖出股票对应的期权净权利金，也可以用于降低下一轮该标的股票的实际成本；
- 卖出期权后中途买回时，计入该笔期权交易最终实现的净盈亏：卖出收到的权利金减去买回支出和相关手续费；
- 不包括未成交订单、理论中间价、预计未来收到的权利金。

累计范围按标的隔离：例如 AAPL 的期权净权利金只能计入 AAPL 股票实际成本，不能用于降低 MSFT 或其他标的的成本。系统必须为每笔交易保存标的、期权类型、开仓现金流、平仓现金流、手续费、成交时间和累计状态，防止漏计或重复计入。

权利金必须以实际成交和账本确认结果为准。

### 2.3 部分股票被 Covered Call 行权后的名义成本调整

如果 Covered Call 以低于当前股票名义成本的执行价被行权，剩余股票的名义总成本允许上升。原因是：已卖出股票按较低价格实现了亏损，这部分亏损由剩余股票承接。

部分行权后的剩余股票名义总成本按以下方式计算：

```text
已卖出股票的名义实现盈亏
= (CC执行价 - 被卖出股票原名义成本价)
  × 被卖出股票数量
```

```text
剩余股票名义总成本
= 行权前股票名义总成本
  - 被卖出股票原名义成本总额
  + 被卖出股票的实际卖出金额
```

等价地：

```text
剩余股票名义总成本
= 行权前股票名义总成本
  + (CC执行价 - 被卖出股票原名义成本价)
    × 被卖出股票数量
```

因此，如果原名义成本为55美元、CC执行价为54美元，卖出一半股票后，剩余股票的名义总成本会因为每股1美元的名义亏损而上升。系统不能简单把剩余股票继续记为每股55美元，也不能只按剩余数量机械截取原成本。

### 2.4 实际成本价

用户定义的实际成本价为：

```text
实际成本价
= (部分行权后剩余股票名义总成本 - 该标的所有累计净权利金)
  / 部分行权后剩余股票数量
```

在部分行权之前，若股票名义成本为每股55美元，累计净权利金使实际成本低于54美元；随后以54美元卖出一半股票，则先按照54美元的名义卖出价格重新计算剩余股票的名义总成本，再减去该标的全部累计净权利金，最后除以剩余股票数量。

按照用户规则，部分股票被行权后，历史累计净权利金全部继续分配给剩余股票；但被低于名义成本的价格卖出所产生的名义亏损，也必须先由剩余股票承接并反映在剩余股票名义总成本中。

实际成本价是本策略检查 Covered Call 执行价的唯一成本基准；券商显示的名义成本价仅作为辅助记录。

如果存在多次 CSP、多个执行价或多个股票批次，必须准确记录剩余股票的名义总成本和数量，不得简单平均或重复扣除权利金。

### 2.4 累计期权费用的记录口径

“权利金链条范围”现在明确为“按标的隔离的累计账本”：

> 同一标的的所有相关卖出期权净权利金，都可以用于计算该标的股票的实际成本；不同标的之间绝不混用。

因此：

- AAPL 的全部相关 CSP、CC 和买回结算盈亏，计入 AAPL 累计账本；
- AAPL 的累计账本可以跨越上一轮股票卖出和下一轮新持股；
- AAPL 的累计账本不能用于 MSFT、QQQ 或其他标的；
- 部分期权或部分股票被行权后，历史累计净权利金全部继续分配给剩余股票。

当股票数量因 CC 被行权而减少时，使用剩余股票名义总成本减去该标的全部累计净权利金，再除以剩余股票数量。若无法确认标的、累计净权利金、剩余名义成本或剩余数量，必须进入人工复核。

## 3. CSP 规则

### 3.1 开仓前条件

只有同时满足以下条件，才允许生成 CSP 候选：

1. 用户愿意在该执行价接收股票。
2. CSP 为现金担保，而不是裸卖 Put 或未经批准的保证金交易。
3. 账户现金足以覆盖所有可能被行权的合约。
4. 交易后仍保留用户设定的现金缓冲。
5. 标的、到期日、流动性、事件风险和其他用户参数均通过风险检查。

### 3.2 全部行权现金覆盖硬性检查

CSP 必须采用最坏情况下的全量行权检查：

```text
总潜在接货现金需求
= 所有相关 CSP 合约数量
  × 每张合约股票数量
  × 对应执行价
  + 预估费用和必要缓冲
```

必须满足：

```text
可用现金 - 总潜在接货现金需求 - 必要现金缓冲 >= 0
```

如果多个 CSP 同时存在，必须把它们全部纳入压力计算，不能只检查新订单本身。

以下情况必须阻止卖出 CSP：

- 不能确认可用现金；
- 全部被行权后现金不足；
- 需要依赖未实现盈利、未来权利金或保证金借款才能接货；
- 现金数据过期或与券商状态不一致；
- 交易会使账户无法承受其他已存在 CSP 的全部行权。

### 3.3 CSP 收益和成本记录

每张 CSP 必须记录：

- 标的；
- 执行价；
- 到期日；
- 合约数量；
- 实际成交权利金；
- 实际费用；
- 净权利金；
- 现金担保金额；
- 是否到期价外、平仓或被行权；
- 关联的持仓链条 ID。

只有在实际成交并完成账本确认后，权利金才可计入累计权利金。

## 4. CSP 结果处理

### 4.1 未被行权

- CSP 失效或按规则平仓；
- 保留已确认的净权利金；
- 股票持仓不增加；
- 可在现金覆盖和其他风险规则通过后继续卖 CSP；
- 不得将未成交、未确认或理论权利金计入实际成本调整。

### 4.2 被行权

- 增加对应数量的股票；
- 从现金中扣除执行价对应的交割金额及费用；
- 建立或更新持仓记录；
- 将用户指定范围内的全部累计净权利金纳入实际成本计算；
- 计算当前股票实际成本价；
- 进入持股状态，后续只允许考虑符合 CC 规则的 Covered Call。

## 5. Covered Call 规则

### 5.1 开仓前必须通过的两项硬性检查

#### A. 执行价必须高于实际成本价

对于每一个拟卖出的 Covered Call，必须满足：

```text
Covered Call 执行价 > 当前被覆盖股票的实际成本价
```

比较对象必须是策略账本计算出的实际成本价，不得使用：

- 券商显示的名义成本价作为唯一依据；
- CSP 的原始执行价作为唯一依据；
- 未成交的理论权利金；
- 未来尚未收到的权利金；
- 与当前持仓无关的上一轮权利金。

如果执行价等于实际成本价，也不满足本策略规则。必须严格高于，而不是大于等于。

如果存在多个股票批次或不同实际成本价，应明确采用批次匹配规则。默认不得把低成本批次和高成本批次混合后掩盖某个批次不满足条件；在批次无法准确匹配时，进入人工复核。

#### B. 全部行权后的股票数量覆盖检查

卖出 Covered Call 前必须满足：

```text
拟卖出的 CC 合约数量
× 每张合约股票数量
<= 当前可用且未被其他卖出订单占用的股票数量
```

全部被行权后，出货数量必须小于或等于现有可覆盖股票数量。

以下情况必须阻止卖出 Covered Call：

- 股票数量不足；
- 股票已经被其他 CC 或卖出订单占用；
- 只能依靠未来买入的股票覆盖；
- 只能依靠未确认 assignment 的股票覆盖；
- 股票数量或合约乘数无法确认；
- 本地账本与券商持仓不一致。

### 5.2 Covered Call 其他条件

除上述两项硬性条件外，还应检查：

- 交易数量为整数合约；
- 执行价、到期日和报价真实可验证；
- 流动性和买卖价差符合配置；
- 除息、提前行权、财报和公司行动风险已检查；
- 交易不会违反单一标的、行业或组合上限；
- 用户知道 CC 会限制股票上涨收益；
- 交易是否需要人工确认。

### 5.3 CC 权利金对实际成本的影响

实际成交并确认的 CC 净权利金，应加入该标的累计净权利金，并继续降低剩余持股的实际成本价：

```text
更新后的实际成本价
= (部分行权后剩余股票名义总成本
   - 该标的全部累计净权利金)
  / 当前剩余持股数量
```

如果 CC 执行价低于原名义成本价，必须先把低价卖出产生的名义亏损转移到剩余股票，更新剩余股票名义总成本；然后再减去该标的全部累计净权利金。部分股票被行权后，不自动按比例剔除历史期权费用，历史累计净权利金全部继续分配给剩余股票。

必须避免以下错误：

- 同一笔权利金重复计入；
- 未成交权利金计入；
- 将其他标的的权利金计入当前标的；
- 无法确认该标的累计净权利金、剩余股票名义总成本或数量时继续交易。

如部分股票被 CC 行权，必须先确认剩余股票数量、被卖出股票的原名义成本、CC实际执行价、低价卖出产生的名义实现盈亏、剩余股票名义总成本和该标的累计净权利金，再按上述规则计算实际成本价。无法准确确认时，必须进入人工复核。

## 6. CC 结果处理

### 6.1 未被行权

- 股票数量保持不变；
- CC 到期或平仓结果写入账本；
- 实际收到的净权利金加入所有累计净权利金，并按用户规则更新实际成本价；
- 在执行价仍高于更新后的实际成本价、股票覆盖仍足够且风险检查通过时，可以继续卖 CC。

### 6.2 被行权

- 减少对应数量股票；
- 记录卖出执行价、实际成交数量和收到的现金；
- 如果执行价低于被卖出股票原名义成本价，先把该名义亏损转移到剩余股票，更新剩余股票名义总成本；
- 结算被卖出股票对应的现金流，并将该标的全部累计净权利金继续分配给剩余股票；
- 如果股票全部卖出，结束当前持仓链条并回到现金状态；
- 如果只卖出部分股票，剩余股票保留其明确的批次成本和链条记录，进入持股状态；
- 不得在实际交割未确认前假设交易已完成。

## 7. 交易阻断规则

以下任意条件成立时，输出 `BLOCK` 或 `MANUAL_REVIEW`，不得直接生成可执行订单：

- CSP 全部潜在行权后现金不足；
- CSP 现金覆盖计算不完整；
- CC 执行价不严格高于实际成本价；
- CC 全部行权后的出货数量超过可覆盖股票数量；
- 无法确定实际成本价；
- 累计权利金账本不完整或可能重复计入；
- 部分行权、部分成交或多批次成本无法分摊；
- 数据过期、缺失或与券商状态不一致；
- 无法确认合约乘数；
- 订单可能形成裸卖或未授权风险；
- 需要依赖未来收益、未来权利金或借款才能满足规则。

## 8. 输出要求

每次建议必须展示：

1. 当前策略状态；
2. 当前股票数量和可用股票数量；
3. 当前 CSP 未平仓数量及全部行权现金需求；
4. 当前持仓名义成本价；
5. 当前累计净权利金；
6. 当前实际成本价；
7. 拟议 CC 执行价；
8. `CC执行价 > 实际成本价` 检查结果；
9. 拟议 CC 全部行权后的出货数量；
10. `出货数量 <= 可覆盖股票数量` 检查结果；
11. 交易费用、滑点和数据时间；
12. 风险和人工审批要求。

## 10. 不明确事项

以下事项仍可在后续版本中配置：

1. 多个 CSP 执行价和多个股票批次同时存在时，如何记录剩余股票的名义总成本；
2. 买回期权的支出是否还需要单独拆分交易费用字段；当前规则按该笔期权交易的最终实现盈亏计入；
3. 是否设置最低绝对利润、最低权利金或最低风险收益率；
4. 是否避开财报、除息日和特殊公司行动。

以下规则已经由用户确认：

- 净权利金 = 卖出期权收到的权利金 - 手续费；
- 同一标的的全部相关 CSP 和 CC 权利金都计入该标的累计账本；
- 上一轮已卖出股票对应的权利金可以用于下一轮同一标的新持股；
- 卖出后买回的期权按两笔交易形成的实际盈利或亏损计入；
- 部分股票或期权被行权后，历史累计权利金全部分配给剩余股票；
- 不同标的之间绝不混用权利金；
- CC 执行价可以低于名义成本价，但必须严格高于实际成本价。
