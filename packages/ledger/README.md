# 期权账本插件

适用于本机 DeepSeek Harness 0.2.1-alpha.2。左侧“期权账本”面板显示全部标的、剩余股数、名义总成本和每股成本、已录入卖出权利金、累计净权利金、实际总成本和每股实际成本。美元金额按整笔填写，内部以整数分保存。

## 使用

1. 新建会话并选择“美股期权模式”，输入框上方自动显示持仓与成本摘要；已有期权会话再次打开时也会显示。点击“打开完整账本”进入录入与管理面板。也可打开左侧“期权账本”，点击“录入 / 调整持仓”。填写当前剩余股数、名义总成本和核对日期。期初累计净权利金只用于尚未逐笔录入的历史金额。
2. 使用“记录期权交易”登记实际成交现金流，或导入旧版 option-ledger.json。导入是去重合并，冲突时整次拒绝；不会静默覆盖持仓。缺失状态的旧交易暂按已平仓导入，并在备注中标记待核对。
3. 新建美股期权模式会话，模型会得到 options_ledger_read 和 options_ledger_propose 工具。模型提交的修改出现在账本待确认区，人工确认后才生效。已有活动会话需重新打开或新建后获取工具。
4. “导出备份”下载可再次导入的 JSON。“撤销上次修改”恢复上一份状态，并保留审计历史。

累计净权利金 = 期初累计净权利金 + 已确认成交的卖出权利金 − 买回支出 − 手续费，含未平仓合约已经收到的现金流，不等于税务已实现损益。每股实际成本 =（剩余股票名义总成本 − 本标的累计净权利金）÷ 剩余股数。零股时无每股实际成本，历史权利金继续保留。组合成本只加总剩余股数大于零且已核对持仓的标的。

通过交易明细的“记录实际行权”处理已经发生的 CSP/CC 交割，先预览再确认，持仓和期权状态在一个事务内更新。CC 部分股票行权按用户 2026-10-13 确认的亏损转移口径：剩余名义成本 = 原名义总成本 − 交割股票原名义成本 + max(交割股票原名义成本 − 交割收入, 0) + 股票交割手续费。例：200 股、原成本 $11,000，以 $54 卖出 100 股，交割股票原成本 $5,500，剩余名义成本 $5,600。盈利不转入，全部出清时名义成本归零。多批次要核对交割批次成本；部分合约行权请先拆分期权交易。手续费不要在期权和股票交割中重复记账。记录可以撤销，重复行权会被拒绝。没有券商连接、行情源或下单功能。TEST 演示只存在于页面内，不写入数据库。初始账本为空，不自动从浏览器 localStorage 读取旧数据。

## 安装和存储

本组合包提供 Host 服务、原生 Client 面板和期权模式专用工具模块。请从仓库根目录按[统一安装步骤](../../README.md#usage)同时安装账本与模式两个组合包，并保留 Harness 的 base 和 web-app。已运行实例更新插件后需重新启动，再刷新页面。

数据库保存在 `$DSH_HOME/data/options-ledger/ledger.sqlite`。它使用 SQLite 事务、WAL、乐观版本控制和修改历史；不同浏览器和模型共用同一份账本。升级时备份整个 DSH_HOME 或通过面板导出账本，运行期间不要只复制 sqlite 主文件而漏掉 WAL。外部 HTTP 入口使用 Harness Connection 自带的登录、Host 和 Origin 检查。

## 验证

`node --test test/*.test.js` 使用系统临时目录内的模拟数据，覆盖计算隔离、未知持仓、零股、负成本、输入校验、重复及冲突导入、并发版本冲突、持久化、撤销、聊天草稿和 Host 接口一致性。网页验收在独立测试实例录入虚构持仓、交易和行权；正式账本仅做模型只读检查，不写入测试交易。

模型端到端对话需要有效模型配置。本插件可以在没有模型/API Key 的情况下打开、录入、计算、导入和导出账本。
