# 自定义期权规则 v2

v1 保留为历史原文，当前计算以此补充为准。用户于 2026-10-13 确认部分 CC 行权采用亏损转给剩余股票口径。

- 累计净权利金按标的隔离：期初历史净额 + 已成交卖出权利金 − 买回支出 − 期权手续费。未平仓已收到的现金流计入，未成交与理论报价不计入。
- CC 部分股票行权：剩余名义成本 = 行权前名义总成本 − 交割股票原名义成本 + max(交割股票原名义成本 − 交割收入, 0) + 股票交割手续费。盈利不转入剩余名义成本；全部出清时名义成本归零。
- 例：200 股每股 $55，以 $54 卖出 100 股，剩余名义成本 = 11000 − 5500 + 100 = $5600。若累计净权利金 $500，每股实际成本 = (5600 − 500) / 100 = $51。
- CSP 实际行权增加股数和执行价对应名义成本，加入股票交割手续费；净权利金不重复记入。
- 实际每股成本 = (剩余名义总成本 − 同一标的全部累计净权利金) / 剩余股数。零股时显示无成本值，历史净权利金保留到下一轮。
- 交割批次成本、合约乘数需要核对。程序不猜测特殊合约或多个批次的对应关系。
- CSP 全部行权现金覆盖、CC 股数覆盖和执行价严格高于实际成本继续作为分析约束。不能把这些局部算术检查当作全部市场风险已核验。
- 不连接券商，不发送订单；模型修改须在账本面板确认。
